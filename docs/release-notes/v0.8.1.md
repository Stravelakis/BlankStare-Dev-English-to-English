## v0.8.1: one panel per tab, Full page that reads the page you are on, a glossary in a second

| | English | Devenglish |
|---|---|---|
| ✨ New | Each tab has its own BlankStare. It opens in the tab you opened it from and keeps that tab's answer. | No `side_panel.default_path`; `openPanel()` calls `sidePanel.setOptions({tabId, path: sidepanel.html?tab=<id>})` then `open()` in the same gesture; queued text carries `pendingTabId`; last answer kept as `tabAnswer:<id>` in session storage |
| ✨ New | Settings has a Full Documentation tab. | Link in the Settings tab bar to docs.stravelakis.com |
| 👍 Better | The term glossary shows up in about a second, next to the answer. | Glossary starts with the answer from the selected text; `chainFor('glossary')` puts Flash-Lite first (measured 1.1s, was ~30s after the answer) |
| 🔧 Fixed | Full page reads the page the tab shows when you press it. | Reads the panel's own tab at click time; clear message when no content script answers |
| 🧹 Removed | The "Read more on" links, the Web search button and the Ko-fi links. | Resource links, DuckDuckGo hand-off and Ko-fi removed; footer links to stravelakis.com |
