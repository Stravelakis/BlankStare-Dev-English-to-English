## v0.8.0: works with no key, picks a working free AI every day, and walks you through it

| | English | Devenglish |
|---|---|---|
| ✨ New | Works straight away, with no account and no key. | Default provider is OVHcloud AI Endpoints' anonymous OpenAI-compatible lane |
| ✨ New | Add a free Google Gemini key for the best answers, read aloud in Gemini's own voice. | Gemini API: `streamGenerateContent` (Gemma 4, Flash-Lite) and the Live `BidiGenerateContent` WebSocket (audio + `outputAudioTranscription`; PCM → WAV) |
| ✨ New | Every day it checks which free AIs work and uses the best one. If one is gone or busy, it moves on by itself. | Daily roster from The Nein `models.json` + each provider's `/models`, hand ranking, fallback list; 404 rests 24h, 429/503/stall 60s, 401/403 benches the provider |
| ✨ New | A 5-step setup the first time, with a key test that takes seconds. | First-run wizard (`onboarded`), `testProvider()` asks 3 models in parallel (66s → 6s) |
| ✨ New | "What do I need first?" and "Do it with me", a checklist you tick off. | New `prereq` and `checklist` modes in `buildUserPrompt()`; `- [ ]` rendered as checkboxes |
| ✨ New | Paste a screenshot and it explains that too. | Ctrl+V image → downscaled JPEG → vision-capable chain |
| 👍 Better | Commands come in copy boxes and steps keep their numbers. The answer says when it is unsure. | Prompt rewrite (verbatim commands in fenced blocks, keep numbers/warnings, page text fenced as material); escaped markdown renderer with `ol start`, blockquotes, copy buttons |
| 👍 Better | A new Settings page that saves by itself, and a calmer, livelier panel. | Settings on WebGL gradient blinds, auto-save; panel: conic edge while streaming, symbol decode while waiting, once-only block fades, prompt bar with chips and sparks; all still under reduced motion |
| 👍 Better | Follow-up questions get a real answer, not "I'm not sure". | Follow-up prompt allows general knowledge for questions the page doesn't cover |
| 🔧 Fixed | The Groq key test and translations had stopped working. | Groq shut down 7 of the 9 hardcoded models; the hardcoded list is gone |
| 🔧 Fixed | Settings no longer pops up every time the extension updates. | `onInstalled` opens Settings on install, and once on the update from <0.8 |
| 🔧 Fixed | Newer Google keys (starting `AQ.`) are accepted. | Key check is length-only for Google; the real test is the API call |
| 🔒 Privacy | Asks for fewer permissions. | Dropped `tabs` and `activeTab` and the `web_accessible_resources` block |
| ⚠️ Heads up | On Google's free tier, Google may read what you send to improve its AI. Don't select private information. | Gemini API Additional Terms, Unpaid Services; stated in the privacy policy and on the Gemini card |
| ⚠️ Heads up | SearXNG search is gone; web search opens DuckDuckGo. | `searxngUrl`, `autoFallback`, `model` settings removed and cleaned from sync storage |
