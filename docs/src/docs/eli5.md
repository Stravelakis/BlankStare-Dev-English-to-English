## Like I'm five

Some grown-ups write in a secret language full of strange words. Programmers do this a lot.

BlankStare is a helper that lives at the side of your web browser. When you see words you don't understand, you colour them in with your mouse, and the helper says the same thing again in easy words.

- If it's still too hard, you can ask it to make it even easier.
- If you want to know more, you can ask it to say more.
- If the words tell you to do something, it can turn them into a list of little jobs. You tick each one when it's done.
- If you take a picture of your screen, it can explain the picture too.
- It can speak English or Greek, and it can read the words out loud to you.

To work, it borrows a very clever computer from a company. You don't need a ticket for that: it works straight away, for free. If you want it faster, you can get a free ticket, called a key, from Google or from Groq.

Every morning the helper checks which clever computers are free that day, so it always picks one that works.

It only reads the words you colour in, unless you ask it to read the whole page. Those words go to the clever computer, so don't colour in secrets.
