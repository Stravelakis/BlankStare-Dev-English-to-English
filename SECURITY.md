# Security Policy

<!-- Maintainer: turn this on once per repo in Settings → Code security → Private vulnerability reporting. -->

## Reporting a vulnerability

Please don't open a public issue for security problems.

Report it privately instead: **Security** tab → **Report a vulnerability** ([direct link](../../security/advisories/new)). Only the maintainer can see it.

You'll get an acknowledgment as soon as it's seen. This is a small project with no fixed response time, but reports are taken seriously and handled promptly.

## Scope

The code in this repository. Problems in third-party dependencies should also be reported to their maintainers.

## Supported versions

Only the latest release gets fixes.
