# Code of Conduct

Short version: be kind.

This project is a space for building, learning, and helping each other. That's it. A few things that make that possible:

- Be respectful and friendly, even in disagreement.
- Assume good intent — most misunderstandings are just that.
- Give generously: feedback, credit, help. Take criticism the same way you'd want it given — kindly.
- Keep discussion on-topic and controversy-free. This isn't the place for it.
- If someone's having a bad time because of something said or done here, that's a problem worth fixing — just say so, no drama needed.

No enforcement bureaucracy, no tribunal. If something goes wrong, open an issue or reach out directly and it'll get sorted like an adult conversation.
