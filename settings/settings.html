💡 What is Groq and how does BlankStare use it?

Groq is a company that runs large AI models (like Meta's Llama) at extreme speed. BlankStare sends the text you select to Groq, and Groq sends back a plain-English explanation.

Example: You select ENOTFOUND getaddrinfo. BlankStare asks Groq. Groq replies: "Your computer can't find the server you're trying to reach — like calling a phone number that doesn't exist."

✅ Why set this up

This is the only key BlankStare absolutely requires. Without it, no explanations are possible.

Web Search

Find more context for anything you've selected, without leaving the sidebar.

🦆 DuckDuckGo Active by default

No setup required. No API key. No tracking. When you click Search in the panel without a SearXNG URL, BlankStare opens a pre-filled DuckDuckGo search in a new tab.

🔐 Optional upgrade: SearXNG Free self-hosted

Run your own private search engine. Results appear inline inside the BlankStare panel — no new tab, completely off the grid. If your SearXNG URL is set and reachable, it replaces DuckDuckGo automatically. If it fails or the field is empty, BlankStare falls back to DuckDuckGo silently.

  1. Enter the full URL of your SearXNG instance
  2. Enable CORS in settings.yml:

🆓 Free limits & pricing

Completely free — you host it, you control it. No rate limits except those you set yourself.

💡 What is SearXNG?

SearXNG is an open-source, self-hosted search engine that aggregates results from Google, Bing, DuckDuckGo and others — without tracking you or serving ads. Perfect if you're already running it for other reasons (like your server setup).

Get started in 3 minutes

BlankStare turns any confusing developer text into plain English, right inside your browser.

1

Add your Groq API key

The only required step. Go to console.groq.com ↗, create a free account, create an API key, paste it in Settings, and click Test.

💡 Takes about 2 minutes and costs nothing.
2

Find something confusing

Go to any page with technical content — GitHub, npm, Stack Overflow, MDN, a terminal log, a README, a config file, an error message. Anywhere.

3

Select the text

Highlight the confusing word, sentence, or block with your mouse. A small ⚡ Explain button appears above the selection.

💡 Or right-click → "Explain with BlankStare" · Or press Alt+Shift+E
4

Click Explain, then open the panel

Click the ⚡ button — it turns green: ✓ Ready — click ↑. Then click the BlankStare icon in your toolbar. The sidebar opens with your explanation streaming in.

💡 Once the panel is open, future explanations go straight to it.
5

Explore the explanation

After the explanation appears:

  • 📋 Copy it · 🔊 Listen · ↓ Go deeper · ↺ Different wording
  • 📺 Search YouTube for a video tutorial
  • 🔍 Web search for more context
  • 💬 Ask a custom follow-up question
  • 📖 Toggle the Jargon dictionary to define every technical term
  • 📄 Click Full page to summarise the entire current page

BlankStare

v0.3.0

BlankStare is a Chrome sidebar extension that translates developer documentation, error messages, READMEs, terminal output, and technical jargon into plain English — instantly, while you browse.

Built for intelligent non-developers who work alongside developers every day: designers, project managers, founders, marketers, and anyone who regularly encounters developer content they need to understand quickly.

✨ Phase 1 — What's built

  • 📊 5 reading levels (ELI5 → Legal/Formal)
  • 🌐 Greek & English — UI, explanations, and voice readout
