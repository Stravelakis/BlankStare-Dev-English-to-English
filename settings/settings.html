💡 What is Groq and how does BlankStare use it?

Groq is a company that runs large AI models (like Meta's Llama) at extreme speed. BlankStare sends the text you select to Groq, and Groq sends back a plain-English explanation.

Example: You select ENOTFOUND getaddrinfo. BlankStare asks Groq. Groq replies: "Your computer can't find the server you're trying to reach — like calling a phone number that doesn't exist."

✅ Why set this up

This is the only key BlankStare absolutely requires. Without it, no explanations are possible.

Get started in 3 minutes

BlankStare turns any confusing developer text into plain English, right inside your browser.

1

Add your Groq API key

The only required step. Go to console.groq.com ↗, create a free account, create an API key, paste it in Settings, and click Test.

💡 Takes about 2 minutes and costs nothing.
2

Find something confusing

Go to any page with technical content — GitHub, npm, Stack Overflow, MDN, a terminal log, a README, a config file, an error message. Anywhere.

3

Select the text

Highlight the confusing word, sentence, or block with your mouse. A small ⚡ Explain button appears above the selection.

💡 Or right-click → "Explain with BlankStare" · Or press Alt+Shift+E
4

Click Explain, then open the panel

Click the ⚡ button — it turns green: ✓ Ready — click ↑. Then click the BlankStare icon in your toolbar. The sidebar opens with your explanation streaming in.

💡 Once the panel is open, future explanations go straight to it.

BlankStare

Dev English → English  ·  Zero cost BYOK

BlankStare is a Chrome sidebar extension that translates developer documentation, error messages, READMEs, terminal output, and technical jargon into plain English — instantly, while you browse.

Built first and foremost for vibecoders — people who build real things with AI coding tools (Claude Code, Cursor, Antigravity, and friends) without coming from a traditional dev background. You already know what an API, a model, a prompt, and git are. BlankStare bridges the rest: the error messages, the config files, the terminal noise that AI agents throw at you mid-build.

Just as useful for anyone else who works alongside developers and regularly hits content they need to understand quickly: designers, project managers, founders, and marketers.
