## What BlankStare is

A panel on the side of Chrome. Select something confusing on any web page — an
error message, a README, a paragraph of documentation — and BlankStare
explains it in plain English, word by word as it is written.

## What it costs

Nothing. It uses **Groq**, which gives free API keys. You bring your own key;
there is no BlankStare account and no subscription.

## Install it

BlankStare is not in the Chrome Web Store yet, so it is installed by hand:

1. Download the code from
   [GitHub](https://github.com/Stravelakis/BlankStare-Dev-English-to-English)
   (Code → Download ZIP) and unzip it.
2. In Chrome, open `chrome://extensions` and switch on **Developer mode**.
3. Click **Load unpacked** and pick the unzipped folder.
4. Settings open by themselves. Paste your free key from
   [console.groq.com](https://console.groq.com).

## Using it

- Select text, then click the small floating button or right-click →
  BlankStare. Or press **Alt+Shift+B** to open the panel.
- Pick a reading level: from "explain like I'm five" to "vibecoder".
- **Go deeper** or **Rephrase** without selecting again; **Full page summary**
  gives 3–5 bullet points of the whole page.
- Every technical word gets a short definition underneath.
- Greek or English, and it can read the answer aloud.

## If a model is busy

Free models have rate limits. Turn on **Auto-fallback** in Settings and
BlankStare moves to the next free model by itself.

## Limits, honestly

- Not in the Chrome Web Store yet — installing needs Developer mode.
- Chrome only.
- Explanations come from an AI model and can be wrong; the resource links
  (MDN, W3Schools, DevDocs) are there to check.
